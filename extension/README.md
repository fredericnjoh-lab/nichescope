# NicheScope SEO — Chrome extension v1.1

Panel flottant sur YouTube (watch / Shorts / Studio) avec score SEO titre · description · tags.

## Install (unpacked)

1. Chrome → `chrome://extensions`
2. Active **Developer mode**
3. **Load unpacked** → dossier `extension/`
4. Ouvre une vidéo YouTube (reload si le panel n’apparaît pas)
5. Icône extension → mot-clé focus, langue, on/off panel

## v1.1 — peaufinage

- Navigation SPA YouTube (`yt-navigate-finish`)
- Shorts + Studio (chips tags)
- Tags absents sur watch → exclus du score (plus honnête)
- Panel : drag, minimize, focus inline + « Déduire »
- Badge score sur l’icône
- Lien Optimize avec `?tab=optimize&q=`
