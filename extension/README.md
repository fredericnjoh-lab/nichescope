# NicheScope SEO — Chrome extension

Panel flottant sur YouTube (watch + Studio) avec score SEO titre / description / tags.

## Install (unpacked)

1. Chrome → `chrome://extensions`
2. Active **Developer mode**
3. **Load unpacked** → sélectionne ce dossier `extension/`
4. Ouvre une vidéo YouTube → panel NicheScope à droite
5. Clique l’icône extension → définis le **mot-clé focus**

## Notes

- Pas de clé API requise (score local, mêmes règles que l’onglet Optimize)
- Tags souvent absents sur la page watch publique (OK sur Studio)
- Icônes générées minimalistes — remplace `icons/` si tu veux
